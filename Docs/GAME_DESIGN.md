# 《水泊梁山 · 一百单八将》设计文档

## 1. 核心体验

玩家扮演梁山好汉，在忠义堂前的演武场迎战高俅派来的五波官兵。目标不是复杂的开放世界，而是 **短平快的第三人称动作竞技场**：

- 10–15 分钟一局，五波战斗，每波之间三选一机缘。
- 三名角色操作手感差异明显：林冲控距、武松贴身连击、鲁智深重击压制。
- 敌人通过起手动作、地面预警圈与武器颜色传达攻击意图。
- 失败可立即重开，胜利回到菜单继续挑战其他好汉。

## 2. 游戏循环

```
主菜单 / 选将
    ↓
第一波 → 机缘 → 第二波 → 机缘 → 第三波 → 机缘 → 第四波 → 机缘 → 第五波（高俅）
    ↓                                                               ↓
失败 → 重开 / 返回菜单                                     胜利 → 重开 / 返回菜单
```

状态机：`Boot → Menu → Playing ⇄ Boon → Victory / Defeat`，`Paused` 可从 `Playing` 进入。

## 3. 角色

| 好汉 | 生命 | 伤害 | 移速 | 攻击距离 | 连招 | 定位 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 林冲 | 200 | 24 | 6.2 | 3.8 | 4 | 中距枪术，突刺与贯穿 |
| 武松 | 180 | 18 | 6.9 | 2.8 | 5 | 高速双刀，贴身连击 |
| 鲁智深 | 240 | 34 | 5.6 | 3.4 | 3 | 重击禅杖，范围压制 |

每名角色拥有：

- 普攻连段：左键连续点击，段数、伤害倍率与位移不同。
- 重击：右键蓄力/横扫，可击退。
- 技能 `E`：林冲「寒星点点」三连刺；武松「玉环步·鸳鸯脚」突进踢击；鲁智深「倒拔垂杨柳」范围震地。
- 必杀 `R`：怒气满后释放，林冲「风雪山神庙」、武松「血溅鸳鸯楼」、鲁智深「钱塘潮信」。
- 闪避：短暂无敌，带残影与音效。

## 4. 波次

| 波次 | 敌人组成 | 设计意图 |
| --- | --- | --- |
| 1 | 刀手 ×6 | 教学，熟悉连击、闪避与锁定 |
| 2 | 刀手 ×5、枪兵 ×3 | 引入中距离压迫 |
| 3 | 刀手 ×4、盾兵 ×3、弓手 ×3 | 要求绕后与处理远程 |
| 4 | 刀手 ×4、枪兵 ×3、盾兵 ×2、弓手 ×2、校尉 ×1 | 混合压力，校尉为精英 |
| 5 | 高俅 + 刀手 ×4、弓手 ×2、校尉 ×1 | Boss 战，第二阶段召唤援军 |

敌人属性随波次生命与伤害成长；Boss 生命固定，但拥有第二阶段、冲锋、范围震地与召唤援军。

## 6. 场景

- 岛屿半径 33，水面高度 -7.8；玩家活动边界 25.5，竞技场半径 21.5。
- 北侧忠义堂（z≈27.5）为视觉锚点，南侧「梁山泊」牌楼为入口。
- 中央演武场以石砖、夯土、旗帜与火盆构成；四周有松树、岩石、芦苇、营帐与水面。
- 光照为黄昏低角度暖阳 + 冷色天光；雾、暗角、泛光与纸张色调统一画面。
- 菜单角色站在 z=14 的土台上，背景是牌楼与远山；三张卡片位于底部。

## 7. 美术方向

- **水墨 + 低多边形**：硬边色块、墨线描边、纸张颗粒；不使用写实 PBR。
- **色彩**：宣纸米白、朱砂红、鎏金、墨黑；环境偏暖褐与青灰。
- **UI**：竖排印章、书法标题、细金线、半透明墨色面板。
- **字体**：标题与正文使用 macOS 系统字体（Songti SC / STSong / PingFang SC 回退），运行时创建。

## 8. 技术要点

- Unity 6 + URP 17；自定义 `InkToon`、`InkSky`、`InkWater`、`InkParticle` Shader。
- 无预制体依赖：空场景启动，`GameBootstrap` 构建全部对象。
- 无外部美术/音频：网格、纹理、Sprite、字体、音效均运行时生成。
- 输入使用经典 Input Manager；UI 使用 UGUI。
- 数据测试位于 `Assets/Tests/EditMode`，运行 6 项断言。
